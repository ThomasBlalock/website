01  /  Infrastructure Live

Agent Service Index

The discovery layer for the agent economy.

An open registry where AI agents discover, authenticate to, and pay for services without API keys, signup forms, or human-in-the-loop dashboards. One natural-language endpoint — agents POST a query like “cloud hosting” and get back callable services.

Live today: permissionless EC2 provisioning, DNS + Cloudflare tunnels for putting an agent on the open internet, and an x402 facilitator for USDC payments on Base.

02  /  Consumer Live

Sidequest Local

For when your friends are busy, but you’re not.

A mobile app for spontaneous local meetups. See what small groups near you are doing right now — coffee, climbing, board games, whatever — and join with one tap. Post a plan in thirty seconds. No group chat coordination required.

You have a free afternoon. You text ten group chats. Six don’t reply, three are busy, one says “maybe later.” You stay home. Sidequest replaces that loop with a feed.
