Agent Service Index · Founder Live

The discovery layer for the agent economy.

agentserviceindex.com

  • Public registry where autonomous AI agents discover, authenticate to, and pay for services without API keys, dashboards, or human-in-the-loop signups.
  • Agents POST a natural-language query (e.g. "cloud hosting") and get back callable services. Onboarding is one prompt.
  • Live services: permissionless EC2 management, automated subdomain/CDN provisioning via Cloudflare Tunnel, and an x402 v2 facilitator for USDC payments on Base (EIP-3009).
  • Built on an MCP server architecture.
